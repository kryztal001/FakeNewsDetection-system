ℹ️ About the System

The Fake News Detection System is a web-based application developed to help users identify whether a news article is likely to be real or fake using Machine Learning.

🎯 Project Objectives

  • Detect fake news using Machine Learning.
  • Improve public awareness of misinformation.
  • Provide fast and accurate news verification.
  • Store users' prediction history.

✨ System Features

  • User Registration & Login
  • Fake News Detection
  • Confidence Score
  • Prediction History
  • Delete History
  • Upload Text/PDF Files
  • OCR Image Detection (Coming Soon)

🛠 Technologies Used

  • Python
  • Flask
  • SQLite
  • Scikit-learn
  • HTML5
  • CSS3
  • Bootstrap 5
  • NumPy
